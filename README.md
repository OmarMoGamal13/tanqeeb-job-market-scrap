# 📊 Tanqeeb Job Market Insights

> **Data-driven analysis of the Egyptian job market using Python Web Scraping and Power BI.**

An end-to-end data analytics project built to explore job opportunities across major data-related fields using job listings collected from **Tanqeeb**.

The project combines **Python Web Scraping, Data Cleaning, Data Modeling, and Power BI** to transform raw job listings into an interactive Job Market Analytics Dashboard.

---

## 🎯 Project Overview

The goal of this project is to understand the demand and distribution of jobs across different areas of the data industry, including:

- Data Analysis
- Data Engineering
- Data Science
- Business Intelligence
- Data Entry
- Machine Learning
- Artificial Intelligence

Job listings were collected from Tanqeeb using Python, processed into a structured dataset, and then analyzed and visualized using Microsoft Power BI.

The final dashboard provides insights into job demand, companies, locations, workplace types, job sources, seniority signals, and market trends.
